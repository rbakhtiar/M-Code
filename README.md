M-

M- is a programming language designed to be simple, readable, and eventually universal.

M- is currently in early development. The goal is to create one language that can eventually be used for applications, games, web development, system tools, and more.

---

🚀 Current Version

M- 0.1

Status: Early Development

---

💻 Example M- Code

Save name = "Lionel Messi"
Save team = "FC Barcelona"
Save goals = 900

Write("Welcome to M-!")
Write(name)
Write(team)
Write(goals)

Output:

Welcome to M-!
Lionel Messi
FC Barcelona
900

---

📖 M- Syntax

Variables

M- uses "Save" to create variables.

Save name = "Lionel Messi"
Save goals = 900

Variables can store text or numbers.

---

Output

M- uses "Write()" to display information.

Write("Hello!")
Write(name)
Write(goals)

---

Comments

Comments begin with "#".

# This is a comment

Save name = "Messi"
Write(name)

Comments are ignored by the M- interpreter.

---

File Extension

M- programs use the:

.m

file extension.

Example:

program.m

---

🧠 M- Language Rules

1. M- keywords use their exact spelling.
2. Variables are created using "Save".
3. Output uses "Write()".
4. Strings use quotation marks.
5. Comments begin with "#".
6. M- code should remain readable and simple.
7. M- syntax should not require Python syntax.

🤖 AI Development Rules

AI tools working on M- should read this README and the files inside "docs/" before generating M- code.

AI-generated M- code must follow the documented M- syntax.

Do not replace M- syntax with Python syntax.

If a requested feature is not currently supported by M-, the M- interpreter should be updated before using that feature in an M- program.
