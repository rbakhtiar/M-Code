M-

M- is a new programming language designed to be simple, fast, and easy to understand.

🚀 About

M- is currently in early development.

The goal of M- is to create a programming language with its own unique syntax and tools.

💻 Example

Save name = "Lionel Messi"

Write(name)

Output:

Lionel Messi

🛠️ Current Features

- Variables with "Save"
- Output with "Write"
- Simple and clean syntax
- ".m" source files

🔮 Planned Features

- "If" / "Else"
- Loops
- Functions
- Math operations
- User input
- Error handling
- M- Standard Library
- Game development support
- M- Pong
- M- IDE
- M- Compiler
